# Vault AI

Provider-neutral AI add-on for Vault Notes. Engine-backed through Greenfield `ai.generate`.

When no provider is configured, the integration path must succeed and the user-visible state must be honest `PROVIDER_NOT_CONFIGURED`. Do not invent completions.

Published ID remains `digital.modula.vault-notes.ai`.

The product owns its host contributions and settings view as a compiled MPS frontend artifact. The generic host renders capability state and must show an honest unavailable state when no provider is configured; it never fabricates generated text.
